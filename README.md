# ExLegal: предложения по страницам услуг

Публичный адрес отчёта: **https://xrenmen.github.io/exlegal-review/**.

Это прототип для согласования. Изменения на действующем сайте ExLegal не внедрены.

Отчёт содержит четыре сравнения «Сейчас → Предлагаемый вид», desktop-пример только ТЗ02, фрагменты отзывов, увеличиваемые снимки и мобильные HTML-примеры.

## Обновление

1. Замените готовые HTML, PNG и связанные ресурсы, сохраняя относительные пути.
2. Сохраните `.nojekyll` в корне публикации. Отдельная сборка и внешние библиотеки для просмотра не требуются.
3. Проверьте страницу `/exlegal-review/`, якорь `#desktop`, увеличение снимков и три телефонных примера. Затем сохраните изменения в репозитории.

Все ресурсы для отображения входят в статический пакет. Ссылки на профили и исходные страницы ведут на ExLegal.
